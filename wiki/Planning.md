## Done and in progress

- Mod lists / profiles - *Completed*
- Mod list sharing and handling (if you have played Arma modded or Total War modded, think like that) - *Completed*
- Mod syncing, getting on the same level as the server you are joining - *Completed*
- Fika headless support, so a headless is served only what it needs - *Completed*
- Window default sizes - *Completed*
- Default filtering and page defaults - *Completed*
- Config protection, so updating a mod stops replacing your settings - *Completed*
- Per-mod pins, so a mod you always want on survives any list you apply - *Completed*
- Server mapping, with who is on the server and where each machine stands - *Completed*
- Local languages based on OS - *Initial release, ongoing*
- Options to use app to monitor mods rather than manage them - *Completed*
- Update notifications, with the app kept running in the tray - *Completed*
- Additional mod footprint monitoring to show data around their usage on your systems - *Planning/developing*
- Never left half-installed - an install that is interrupted (the app closed or the PC lost power part way) is shown as partly installed the next time the app runs, so a reinstall puts it right - *Completed*
- Profile backups - your SPT profiles are backed up before any install, update, remove, disable or list apply, and can be put back from Options - *Completed*
- Held-back updates - an update that would break another installed mod isn't offered, and the card says why - *Completed*
- Fika warnings - asked before installing a version sp-mod marks as not working with Fika on a Fika install, and warned before removing a mod that may have changed your profile - *Completed*
- Faster downloads - up to three at once while installs carry on one at a time, with retry and resume - *Completed*
- A downloads bar along the bottom of the window while anything downloads or installs - *Completed*
- SPT upgrade check - pick a newer SPT and see which of your mods are ready for it - *Completed*
- Mod descriptions shown in full - tabs, tables and GIFs as sp-mod shows them - *Completed*
- Filter by when a mod was published or last updated, and search titles only or titles and teasers - *Completed*
- Select several mods on Installed - Ctrl-click, Shift-click, Ctrl+A, in every view - and update, enable, disable or remove them together - *Completed*
- An Update button on each card and List row - *Completed*
- Switching to any version - already in Details and versions, which lists every release with Update, Downgrade or Redownload - *Completed*
- Author pages, and following an author - their new mods come with the update notifications - *Completed*
- A right-click menu on every mod - *Completed*
- Mod tools - launch the programs a mod ships from the Server page - *Completed*
- Server without its window - the server log live on the Server page, and the game closed along with the server - *Completed*
- Direct launch - start the game from the Profile page without SPT's launcher (experimental, off by default, SPT 4.1.3 and later) - *Completed*
- Diagnose logs - reads the server, BepInEx and game logs, names the mod at fault, and builds a report with private details taken out - *Completed*
- Quick view - hover a mod for a preview - *Completed*
- Page size options, including endless scrolling - *Completed*
- Mod comments in the app - *Completed*
- Version conflicts - switch to the version that suits the most mods, or disable the one asking - *Completed*
- Dependencies on Apply - a list's preview offers the mods its mods need that the list doesn't name - *Completed*
- Installed versions checked against your SPT (and Fika) - *Completed*
- Themes - five built-in looks (Tarkov, OLED black, High contrast, Soft, Steam) and an editor to make and share your own - *Completed*
- Ignore mods - hide listings you never want to see from Browse, author pages and new-mod notifications - *Completed*
- Profile stats - the SPT launcher's profile page in the app: raid record, money and level progress for the picked profile, on a new Profile page beside the Server page - *Completed*
- Addons - every installed addon gets its own card, removing or disabling a mod can take its addons with it, and mod lists offer an addon's missing mod and catch addon versions that won't fit - *Completed*
